# Happy Birthday My Love

A romantic birthday surprise with a passcode screen, photo memories, a personal message, and looping background music.

## Live site

https://vdroidt.github.io/HappyBirthday/

## Run locally

Install Node.js, then run:

```sh
npm install
npm run dev
```

## GitHub Pages

The site deploys to GitHub Pages whenever changes are pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The workflow builds the app as a static site and publishes it at the project URL above.
